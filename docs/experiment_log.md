## 時間序軌跡

### 0. 啟發式基線（`path_enum_scoring`）

| 項目 | 內容 |
|------|------|
| 計分 | 手工 heuristic（dt／emb／相機跳數等） |
| 0507 候選 | 26 tracks；合法邊 ~41（早期）→ 後隨拓撲擴充增加 |
| Top-1 特徵 | 分數尺度大（例：~208）；無概率解釋 |
| 問題 | 證據可加性、先驗與觀測混用、難做 out-of-sample 校準 |

對照檔：`comparison_20260507.md`（啟發式 vs 初版 LLR）。

---

### 1. 原則修正：改為 LLR 計分（結構不變）

| 類型 | **原則修正** |
|------|-------------|
| 內容 | 邊／節點改為對數似然比：`LLR_emb`、handoff 的 `LLR_dH`、可選 `LLR_dt`；路徑分 = Σ node + Σ edge |
| 收縮 | `w = n/(n+10)` |
| handoff | OVERLAP 或短 dt+H → 不算 `LLR_dt` |
| 依據 | 分數需可機率解釋；硬規則（拓撲／MIN_TRANSIT／emb gate）與軟證據分離 |

早期 0507（node evidence 仍關）：Top-1 路徑常與啟發式同，P≈0.72（樣本極少時先驗為主）。

---

### 2. Bug 修復：超節點邊 dt 改用聯集端點

| 類型 | **bug 修復** |
|------|-------------|
| 問題 | `_best_member_edge` 用「emb 最大成員對」端點算 dt，而非超節點聯集 `max(sb.t_start−sa.t_end,0)` |
| 修復後 | 合法邊 179→174；多條超節點邊 dt 縮短（例 `{23,22}→09_42`：31.99→**20.40**） |
| 依據 | 超節點時間窗應為成員聯集；否則 MIN_TRANSIT／handoff 判斷失真 |
| 報告 | `comparison_gt_20260507.md` |

---

### 3. 原則修正：結構三件套 + 凍結校準

| 修正 | 內容 | 依據 |
|------|------|------|
| emb gate | 硬門檻 → **0.80**（`llr_gate_config`） | 鑑別交給 `LLR_emb`，硬門只擋离谱 |
| 超節點 | 跨鏡共存 +（OVERLAP 或 H×dH&lt;80）→ union-find | 同人同時多鏡不應當兩點 |
| 節點證據 | `w·llr(sim\|GT, sim\|nonGT)` | query-sim 提供點分數 |
| 校準 | **`calibration_gt0507.pkl`**（in-sample GT；OOS 禁用 0528 調參） | 分布與轉移先驗來源固定 |

**消融凍結 B 組**：`dt-scoring=off`（tau 無實測）、`transition-prior=off`。

| 0507 @ B（hop1 仍 2.0 時） | prec | rec | P | score |
|---------------------------|------|-----|---|-------|
| Top-1（含 `09_42`） | 0.909 | 0.909 | 0.282 | 37.501 |

## 遺留事項

1. **三個搭便車節點**：`K8-07_1`、`K8-07_93`、`K8-09_167`  
   - 仍出現在 0528 v1.0 Top-1（非 GT）。  
   - `09_96`/`07_139` 已因分段排名出局；上述三者未觸發「假設內共存矛盾」剔除，且對單段分數仍有貢獻。  
   - 後續可考慮：節點證據強化、更嚴的共存／同鏡排斥、或人機覆核，**不宜再對 0528 調校準**。

2. **自校準樣本不足**  
   - `calibrate_self.py`：正樣本僅超節點成員對（0528 n=4）→ `emb` shrink **w≈0.29**。  
   - 需更多幾何確認的重疊／handoff 對，w 接近 1 後才適合啟用強 `LLR_emb` 與轉移先驗實驗。

3. **轉移先驗待證據**  
   - 條件「`emb` w 明顯上升（≈1）」未滿足 → 未跑 `--transition-prior on`。  
   - 先驗 `p_edge` 的非 GT 估計已具備草圖（多成員超節點相鄰／合法邊），但**證據權重不足時不上場**。

4. **最終驗證需未見過的第三資料集**  
   - 0528 已用於拓撲／MIN_TRANSIT／分段行為診斷 → **不再算純 OOS**。  
   - 論文宣稱泛化前，需凍結 v1.0 後在**第三日／第三人**上只評估、不改規則。
