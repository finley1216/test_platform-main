# 追蹤流程快速開始

從 `git clone` 到產出 merge / filter 結果的完整步驟。

## 前置說明

| 項目 | 是否在交付包內 | 說明 |
|------|--------------|------|
| 程式碼 | 是 | `BoT-SORT/`、`CLIP-ReID/`、`query_filter.py`、`track_path_m9.py` |
| **路徑枚舉（交付用）** | 是 | **`track_path_m9.py`（M9）** ← 學弟請用這個；可選串 `query_filter.py` |
| 路徑枚舉（M0 基準） | 已收起 | `scripts/tracking/track_path_m0.py`（交付流程不需要） |
| 實驗檔（M1–M8 等） | 是（可忽略） | `scripts/tracking/track_path_minimal.py` |
| query 圖 | 是 | `p9.jpg`（人員）、`BSH-5613.jpg`（車輛0507）、`wc.png`（車輛0528） |
| `Homography/` | **建議是** | Homography `H_*.npy`（path_enum 跨鏡同物件判斷；無則仍可跑，但少 H 加成） |
| `../video/` | **否** | 原始影片（Step 2 gdown 下載） |
| `backend/segment/` | **否（僅 .gitkeep）** | segment 分析結果（Step 3 API 產生；或手動複製） |
| `CLIP-ReID/pretrained/*.pth` | **否** | 模型權重（Step 4 `download_weights.py`） |
| `../output/` | **否** | mapping、crop、追蹤／path_enum 結果（流程自動產生） |

## 流程總覽

```
git clone → pip install
  → [1] gdown 下載影片 → ../video/{category}/
  → [2] 啟動 backend
  → [3] call API 產生 segment → backend/segment/
  → [4] download_weights
  → [5] export mapping
  → [6] query_filter 一鍵追蹤 → merge 目錄
  → [7] track_path_m9 路徑枚舉（或一步 --dataset 串起來）
```

### 路徑枚舉（M9，交付）

已有 merge 目錄時：

```bash
python3 track_path_m9.py ../output/query_filter_merge/人員追蹤_20260507
```

一連串（先 `query_filter` 再 M9）：

```bash
python3 track_path_m9.py --dataset 人員追蹤_20260507
```

M0 基準（已收起，交付不需）：`scripts/tracking/track_path_m0.py`

## 1. Clone 與依賴

```bash
git clone https://github.com/finley1216/test_platform-main.git
cd test_platform-main

pip install -r requirements-tracking.txt
```

---

## 2. 下載影片（gdown）

人員追蹤 20260507 測試影片（[Google Drive 資料夾](https://drive.google.com/drive/folders/1HKUcJzfewkqHCJba4WH5ShR50iHEHYHu)）：

```bash
python3 scripts/download_tracking_videos.py --dataset 人員追蹤_20260507
```

輸出至 `../video/人員追蹤_20260507/`：

```
../video/人員追蹤_20260507/K8-01.avi
../video/人員追蹤_20260507/K8-08.avi
...
```

自訂 Drive 資料夾：

```bash
python3 scripts/download_tracking_videos.py \
  --dataset 我的類別_20260528 \
  --folder-url "https://drive.google.com/drive/folders/XXXX"
```

---

## 3. 啟動 backend + 產生 segment（API）

影片就緒後，需啟動 backend（docker-compose 或本地），再對每支鏡頭呼叫 segment pipeline：

```bash
# 例：docker-compose up -d backend  （依你的部署方式調整）

python3 backend/scripts/rerun_segment_cameras.py \
  --category 人員追蹤_20260507 \
  --cameras K8-01 K8-05 K8-07 K8-08 K8-09 K8-20 K8-21 K8-22 K8-23
```

`video_id` 格式為 `{category}/{camera}`，產出：

```
backend/segment/人員追蹤_20260507_K8-08/
  ├── 人員追蹤_20260507_K8-08.json
  ├── segment_*.mp4
  └── yolo_output/object_crops/...
```

**API 前置：** backend 運行中、GPU/vLLM、YOLO 權重、`.env` 的 `MY_API_KEY`。

---

## 4. 下載 CLIP-ReID 權重

```bash
python3 CLIP-ReID/download_weights.py person    # 人員追蹤
python3 CLIP-ReID/download_weights.py vehicle   # 車輛追蹤
```

---

## 5. 匯出 mapping + 同步 crop

```bash
python3 backend/scripts/export_category_crop_time_mapping.py \
  --category 人員追蹤_20260507 \
  --base_date 2026-05-07 \
  --labels person
```

預設輸出到 `../output/`。完成後腳本會印出下一步指令。

---

## 6. Query 篩選 + BoT-SORT + merge + filter

```bash
python3 query_filter.py \
  --dataset 人員追蹤_20260507 \
  --merge-rule triple \
  --force
```

別名：`--dataset 人員0507`

輸出：`../output/query_filter_merge/人員追蹤_20260507/`

---

## 7. 跨鏡頭路徑枚舉 + Top-1 拼圖

```bash
python3 path_enum_scoring.py \
  ../output/query_filter_merge/人員追蹤_20260507 \
  --sim-min 0.85
```

- 輸入：Step 6 的 `*_merged.json` + `filter_results/`（kept）
- 時間戳：Step 5 的 `../output/{dataset}_crop_time_mapping.json`
- 輸出：`../output/path_enum/`
  - `{dataset}_top1_collage.png` 路徑拼圖
  - `{dataset}_top1.json` 路徑摘要
  - `{dataset}_out.txt` 文字報告

建議上游 `--tracklet-sim-thresh 0.85` 時，這裡 `--sim-min` 也設 0.85。

---

## 進階：略過 API（已有 segment）

若 `backend/segment/` 已從其他環境複製，可從 Step 4 開始。

## 常見問題

**Q: `segment 目錄不存在` 或找不到 `K8-*`**
→ 先完成 Step 3 API，或手動放入 segment 資料。

**Q: API 404 找不到影片**
→ 確認 `../video/人員追蹤_20260507/K8-08.avi` 存在（Step 2）。

**Q: 權重下載失敗**
→ 手動下載 `.pth` 到 `CLIP-ReID/pretrained/`。

**Q: 只跑單一鏡頭**
→ `--video-ids 人員追蹤_20260507_K8-08`。
