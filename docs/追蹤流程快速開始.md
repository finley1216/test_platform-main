# 追蹤流程快速開始

從 `git clone` 到產出 merge / filter 結果的完整步驟。

## 前置說明

| 項目 | 是否在 git 內 | 說明 |
|------|--------------|------|
| 程式碼 | 是 | `BoT-SORT/`、`CLIP-ReID/`、`query_filter_botsort_merge_filter_dataset.py` |
| `backend/segment/` | **否** | 平台 segment 分析結果（JSON + crop），需自行放入 |
| `CLIP-ReID/pretrained/*.pth` | **否** | 模型權重，執行 `download_weights.py` 取得 |
| `output/` | **否** | mapping、crop 同步、追蹤結果（預設在 repo 上一層 `../output/`） |
| query 圖 | 是 | `p9.jpg`（人員）、`wc.png` / `BSH-5613.jpg`（車輛） |

## 1. Clone 與依賴

```bash
git clone https://github.com/finley1216/test_platform-main.git
cd test_platform-main

pip install -r requirements-tracking.txt
```

## 2. 準備 segment 資料

`backend/segment/` 需包含形如 `{類別}_K8-XX/` 的目錄，例如：

```
backend/segment/人員追蹤_20260507_K8-08/
  ├── 人員追蹤_20260507_K8-08.json
  └── yolo_output/object_crops/...
```

從既有環境複製或建立 symlink 皆可：

```bash
mkdir -p backend/segment
ln -s /path/to/人員追蹤_20260507_K8-08 backend/segment/
```

## 3. 下載 CLIP-ReID 權重

```bash
python3 CLIP-ReID/download_weights.py person    # 人員追蹤
python3 CLIP-ReID/download_weights.py vehicle   # 車輛追蹤
```

若本機已有舊版 `../CLIP-ReID/pretrained/`，會自動複製；否則透過 gdown 從 Google Drive 下載。

## 4. 匯出 mapping + 同步 crop

```bash
python3 backend/scripts/export_category_crop_time_mapping.py \
  --category 人員追蹤_20260507 \
  --base_date 2026-05-07 \
  --labels person
```

預設輸出到 `../output/`（與 repo 同層的 `output/` 目錄）：

- `../output/人員追蹤_20260507_crop_time_mapping.json`
- `../output/人員追蹤_20260507_K8-*/`（各鏡頭 crop）

完成後腳本會印出下一步指令。

## 5. Query 篩選 + BoT-SORT + merge + filter（一鍵）

```bash
python3 query_filter_botsort_merge_filter_dataset.py \
  --dataset 人員追蹤_20260507 \
  --merge-rule triple \
  --force
```

別名：`--dataset 人員0507`

### 輸出位置

```
../output/query_filter_merge/人員追蹤_20260507/
  ├── *_crop08_botsort09_merged.json
  ├── *_crop08_botsort09_merged.png
  └── filter_results/
```

embedding 快取與 crop 同根：`../output/embed_cache/`。

## 車輛追蹤範例

```bash
# Step 4
python3 backend/scripts/export_category_crop_time_mapping.py \
  --category 車輛追蹤_20260507 \
  --base_date 2026-05-07 \
  --labels car

python3 CLIP-ReID/download_weights.py vehicle

# Step 5（車輛略過 Step 2 intra-filter）
python3 query_filter_botsort_merge_filter_dataset.py \
  --dataset 車輛追蹤_20260507 \
  --merge-rule triple \
  --force
```

## 常見問題

**Q: `segment 目錄不存在`**
→ 執行 Step 2，將 segment 資料放入 `backend/segment/`。

**Q: `找不到 mapping`**
→ 先完成 Step 4 export。

**Q: 權重下載失敗**
→ 手動下載 `.pth` 放到 `CLIP-ReID/pretrained/`，再重試。

**Q: 只跑單一鏡頭除錯**
→ 加 `--video-ids 人員追蹤_20260507_K8-08`。
